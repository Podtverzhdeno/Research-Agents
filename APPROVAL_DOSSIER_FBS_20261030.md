## 3. Отсекающие испытания

1. 3.1.15: действительный ключ агента + revoked mandate => отказ, никакого обхода прав по AI-решению.
2. H1: поставщик меняется, гарантия/escrow не меняются без правильной договорной процедуры; сравнить существующий BPM+продуктовый набор.
3. H2: сговор аффилированных поставщиков цифровых свидетельств не запускает платёж по недостоверному исполнению.
4. 4.1.13.6.2: два конкурентных распоряжения на один цифровой актив не должны приводить к двойной выдаче.
5. Accounting: новое обязательство не может автоматически попасть в неверный счёт, потому что AI определил тип операции.
6. 3 NO_SPECIAL_CHANGE: при обнаружении нового самостоятельного обязательства конкретной ФБС решение переоткрывается.

## 4. Изменения редакции после проверки внешнего контекста

- NIST, 27.10.2026, уже предлагает десять design tenets для agent identity, delegation и authorization: идентификация агента сама по себе не инновация 2036, а база для безопасного доступа.
- BoE/FCA, 26.10.2026: 80% респондентов используют агентов, но только 2% сообщили о широкой автономии; банк не должен выдавать зрелость A2A-рынка за подтверждённый спрос.
- IMF, 24.04.2026: разделить intent, authorization, settlement; AI-инструкция не отменяет банковскую авторизацию и расчётную финальность.
