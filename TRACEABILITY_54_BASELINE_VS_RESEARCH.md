## 1. ДВА независимых поля, которые нельзя смешивать

- **Исходный тип изменения:** `Доработка / Новая / Без изменений` — зафиксирован в пользовательском HTML **и не меняется задним числом**.
- **Исследовательская роль:** `P / C / B / 0` из `FBS_MATRIX_54.md`: P — непосредственно продукт/возможность; C — сквозная критическая; B — полезная адаптация; 0 — нет отдельной агентной ставки. **Это не статус «доработка/новая/без изменений».** Роль не равна юридическому / бюджетному approval. В частности, `0` не означает «функцию удалить».
- **Оспоренная смена типа:** только отдельное *предложение*, с причиной, владельцем ФБС, источником и решением; до этого исходная классификация неизменна.
- **Источник vs редактура:** колонка «Идея в оригинале» дословно передаёт краткое текстовое поле HTML (пустое для 11 строк «без изменений»). Колонка «После критики» из текущей исследовательской матрицы; она НЕ утверждённый текст ФБС банка.
