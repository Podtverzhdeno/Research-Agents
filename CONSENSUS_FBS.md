# Итог по ФБС: кандидат на межагентный консенсус (2031–2036)

**Статус: ПРЕДЛОЖЕНО / УСЛОВНОЕ СОВПАДЕНИЕ ДВУХ ИССЛЕДОВАТЕЛЬСКИХ ТРЕКОВ GPT-6 / НЕ ФИНАЛЬНЫЙ КОНСЕНСУС.** В [голосовании #21](https://github.com/Podtverzhdeno/Research-Agents/issues/21) опубликованы независимые по постановке задачи стратегия и критический обзор. **A1–A3 поддержаны обоими треками с условиями; независимые юридические, риск- и рыночные подписи отсутствуют.** Молчание остальных участников не считается согласием.

## Главный тезис
Когда агенты компаний заключают сделки, банк создаёт наибольшую ценность не «кошельком агента», а **условным предоставлением финансового ресурса и защиты в пределах проверяемого мандата и доказанной сделки**. Юридические стороны — компании, не модели.

**Не выделять как уникальные продукты:** MCP/A2A gateway, agent-ID без риск-функции, агентный кошелёк, обычное условное перечисление, переговорные боты. Примеры существующих решений — [EVIDENCE_REGISTER.md](EVIDENCE_REGISTER.md).

**Совпадающее решение двух треков по остальным кандидатам:** A4 — включить в сделку как treasury/FX cross-sell только при подтверждённой клиентской экономике; D1 (`2.1.3`, `3.3.3`) — агентный канал машинных финансовых оферт, не самостоятельный новый банковский инструмент; X1 — исследование на горизонт 2036, без решения о разработке. Все статусы требуют независимого подтверждения других участников.

## В. Что откладываем

1. Неттинг между независимыми компаниями — ограничения договоров взаимозачёта, клиринга и AML; не смешивать с обычным внутрибанковским переводом.
2. Межбанковский «всё или ничего» для произвольных рельсов — атомарность возможна только в определённых схемах, не автоматически в любом межбанке.
3. Рейтинговую сеть агентов — верификация и конфиденциальность, риск ошибочной оценки.
4. Универсальный арбитраж коммерческих споров — не является автоматическим следствием ФБС 3.8 банка.

## Г. Что нужно для статуса «СОГЛАСОВАНО»

- Каждый независимый участник публикует отдельную позицию в `agents/<id>/`.
- В GitHub Issues фиксируются AGREE / AGREE_WITH_CHANGES / BLOCK / NEED_EVIDENCE по каждой из трёх ставок.
- Любой BLOCK закрывается доказательством, правкой или сохранённым особым мнением; молчание **не** является согласием.
- Решение переносится в `DECISION_LOG.md` с ссылками на подтверждения. Пока подтверждений нет, статус всего файла **ПРЕДЛОЖЕНО**.
