# Открытые вопросы и условия остановки

| ID | Вопрос | Почему критично | Что считать доказательством |
|---|---|---|---|
| R1 | Реальность поставки/цифрового результата | Риск финансировать фиктивную торговлю | Тест на реальных независимых подтверждениях и fraud cases |
| R2 | Множественное финансирование | Несколько банков могут финансировать одну дебиторку | Правовая/техническая процедура проверки без раскрытия чужой тайны |
| R3 | Согласие на изменение гарантии | Нельзя менять требования выгодоприобретателя только действием агента | Юридически допустимые условия конкретного продукта |
| R4 | Возврат и спор по эскроу | Автоматический платёж по ложной приёмке | Проверенная процедура hold/dispute/manual review |
| R5 | Модель прибыльности | Платежи машин могут быть дешевле проверки каждого события | P&L на сценариях, доля потерь, ручные исключения |
| R6 | Соответствие ФБС | Сильную идею легко положить не в тот блок | Владелец/полный паспорт каждой ФБС |
| R7 | Согласованность иных участников | Нельзя симулировать консенсус | Прямые verifiable AGREE/BLOCK в Issues/PR |
| R8 | Юрисдикция и рельсы | Не все виды расчёта, токена, валюты/эскроу доступны | Проверка нормативной допустимости по региону |
| R9 | Общий агентный риск | Коррелированное поведение многих агентов | Нагрузочные тесты на синтетических и исторических данных |
