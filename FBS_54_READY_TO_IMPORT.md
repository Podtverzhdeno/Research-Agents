## Использование

- Для внесения в исходный HTML перенести **короткую формулировку** в строку соответствующей ФБС; **не** заменять историю `40/3/11` новыми решениями без утверждения владельца.
- По каждой спорной ФБС открыть [развёрнутую карточку с CJM и ограничениями](FBS_54_ACTIONABLE_COMPLETION.md); метрика в этой таблице — цель проверки, **не факт её достижения**.
- Для `Без изменений` предложение описывает **сохранение действующего процесса**, а не новую доработку. Особый случай `4.1.11` — отдельная гипотеза о переходе в «Доработка» при договорных основаниях.
- Для `4.1.13.1` и `4.1.13.2` предложения изменяют **смысл содержания**, а не статус источника: управление физической наличностью и физической инкассацией соответственно.
- Если риск, правовое основание, владельца, системную границу нельзя подтвердить, предложение остаётся `PROPOSED` и не должно попадать в утверждённый банковский паспорт.
