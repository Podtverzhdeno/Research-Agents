## 1. Общий вердикт

Поддерживаю **A1 (финансирование), A2 (гарантия/обеспечение), A3 (эскроу)** как единое продуктовое ядро, а **A4 (казначейство)** как отдельную инвестиционную ветку — **строго при выполнении блокирующих условий**. **X1 (сетевой многосторонний зачёт)** оставить `RESEARCH_ONLY`. Я не предлагаю создавать пятый независимый продукт «кошелёк», «паспорт агента» или «MCP/A2A gateway».

Лидирующая новая **продуктовая композиция**, которую стоит проверить: **лимит на исполнение сделки**. Банк резервирует утверждённую кредитную/гарантийную способность юридического лица; расходование по стадиям возможно только при проверенном мандате и документальном подтверждении соответствующего события. Финансирование, гарантия, эскроу и расчёт — отдельные банковские договоры/сервисы, не один юридический продукт. Уникальность мирового решения НЕ доказана.

## 3. Независимый red-team: почему прибыль может не возникнуть

| Риск | Как рушится идея | Контрмера / gate |
|---|---|---|
| **Фиктивная поставка** | ERP-статус/подпись не доказывают существование товара; банк финансирует подложный заказ. | Подтверждение должника, независимый акт/источник, анти-дублирование, кредитная проверка. |
| **Двойное финансирование** | Одно право требования заложено/уступлено нескольким организациям. | Юридическая чистота уступки/обеспечения, проверяемый идентификатор требования, внешняя сверка. |
| **Гарантия со снижаемым покрытием** | Уменьшение обеспечения ошибочно трактуется как уменьшение обязанности по гарантии. | Разделить: обязательство бенефициару, внутреннее обеспечение, цена будущих выпусков/изменений. |
| **Ложная приёмка escrow** | Два сговорившихся агента подделывают «независимые» доказательства. | Независимость источников, dispute window, ручной override и механизм возмещения. |
| **Синхронный вывод ликвидности** | Тысячи агентных FX/депозитных решений ухудшают ликвидность банка/клиента. | Совокупные лимиты на юрлицо и сеть, очередь платежей, Circuit breaker за пределами LLM. |
| **Отсутствие оплаты за «доверие»** | Клиент предпочитает обычный аккредитив/гарантию/факторинг без A2A-премии. | Сравнение полной стоимости с базовым продуктом; комиссия только за проверяемый результат. |
| **Сетевой неттинг без сети** | Юридические требования не зачитываются между множеством сторон; низкая плотность встречных сделок. | X1 остаётся PoC, пока нет правового механизма, достаточного объёма и default waterfall. |

**Экономика проверки:** `risk-adjusted contribution = процентный доход + комиссии + FX-результат − стоимость фондирования − ожидаемые потери − стоимость капитала − проверки/диспуты − интеграционные затраты`. Чисел и доказанной положительной маржи пока нет.

## 4. Рыночная проверка (факт ≠ гипотеза)

1. **Visa/BILL/Billtrust (20.10.2026)**: live pilot выполняет платежи по **уже одобренным** инвойсам. Не самостоятельное B2B кредитование и не свободное агентное принятие коммерческих обязательств. [Первичный источник](https://investor.visa.com/news/news-details/2026/Visa-BILL-and-Billtrust-Launch-First-Live-Pilot-for-Trusted-AI-Agent-Payments-Between-Buyer-and-Supplier-Platforms/default.aspx).
2. **Oracle (14.04.2026)**: агенты для проверки заявок на гарантии и настройки программ SCF уже объявлены. Уникальность «агент оформляет заявку» отсутствует. [Источник](https://www.oracle.com/news/announcement/oracle-financial-services-extends-agentic-ai-platform-to-corporate-banking-2026-04-14/).
3. **VCAP draft-stone-vcap-02 (04.09.2026)**: independent Internet-Draft содержит verified deliverables / escrow / refund; **не стандарт IETF и не промышленный банковский продукт**. [Текущая версия](https://datatracker.ietf.org/doc/draft-stone-vcap/).
4. **BIS Agorá (27.05.2026)**: прототип атомарных межвалютных расчётов существует; «атомарный платёж» сам по себе не новая ставка. [BIS](https://www.bis.org/publications/project-agora-shared-programmable-platform-wholesale-cross-border-payments).
5. **AAA Legal Context Protocol (24.06.2026)**: слой согласия, условий и разрешения споров уже разрабатывается; отдельно «A2A-арбитраж» не уникален. [AAA](https://www.adr.org/press-releases/aaa-and-industry-leaders-launch-legal-protocol-for-agentic-commerce/).
6. **BIS Agenti (14.10.2026)**: центральные банки исследуют шоки и задержки платежей при поведении агентов. Это повод для стресс-тестов A4/X1, не признак готового решения. [BIS](https://www.bis.org/node/87745).
7. **Bank of England/FCA survey (26.10.2026)**: 80% респондентов с агентами в production, но лишь 2% с широкими полномочиями; массовость 2031–2036 — СЦЕНАРИЙ. [Опрос](https://www.bankofengland.co.uk/report/2026/artificial-intelligence-in-uk-financial-services-2026).

## 5. Рекомендация для общей карты

- **A1–A3 — объединить в единый клиентский сценарий**: контракт → мандат → проверенное событие → лимит/гарантия/эскроу → расчёт → спор. Это **три различимые ФБС и продуктовые обязательства**, а не один новый выдуманный код.
- **A4 — оставить самостоятельным** только при наличии достаточной клиентской задачи с реальным FX/ликвидностью и подтверждённой экономикой.
