# Round 4 — Kill the Winner: проверка, действительно ли shortlist лучший

**28.10.2026 · GPT-6 Strategy · DRAFT CHALLENGE / НЕ голос о согласии остальных**

**Объект:** [каноническое решение](../../RESEARCH_DECISION_FBS_2031_2036.md), [матрица 54](../../FBS_MATRIX_54.md). Условия продуктового банковского запуска не подтверждены. Это попытка **опровергнуть P1/P2**, а не ещё один одобрительный обзор.

## 1. Структурная ошибка: «лучший продукт банка» не равен «лучшая ФБС из 54»

**P1 финансирование/факторинг отсутствует в 54-кодовой карте.** Нельзя одновременно помещать P1 в первое место **внутри исходных 54**. Нужно две отдельные рейтинговые задачи:

- **R-BANK:** где банк может заработать / снизить риск — среди всех способностей, включая **отсутствующие кредитование, ликвидность, риск**.
- **R-54:** какие изменения в данных **54** способностях приоритетнее. В этой задаче `4.1.22.2` — прямой финансовый продукт; `3.1.9`, `4.1.1`, `2.1.3`, `3.3.3`, `6.1.5/6` — претенденты на **выше** `4.1.22.2` по платформенной необходимости и охвату. Сравнение обязанностей/продуктов по одной оси нелегитимно.

**Вынужденное решение:** в каждом финале хранить два списка и метку `OUT_OF_SCOPE_54` для A1. Если пользователь требует идеи **исключительно под 54**, первым продуктом в данном срезе становится `4.1.22.2`, а P1 помещается в перечень необходимых изменений **полного**, пока неизвестного каталога.

## 3. Новая конкурентная опасность: агентный канал сжимает маржу

**Контрсценарий 2031:** ERP-агент клиента получает пять машиночитаемых банковских оферт. Банк платит за данные/доверие, но клиент выбирает минимальный spread. Самые надёжные требования уходят дешёвым банкам, у остальных остаются худшие риски. Из роста числа A2A-сделок **не следует** доход банка. При такой модели корпоративный `D1` может быть **защитой доступа к спросу**, не доказательством монетизации.

**Метрики:** `agent_quote_impression -> selected -> executed`, доля выигранных заявок по рисковым сегментам, `RAC` на сделку, adverse selection, cost per verified fact. Нет данных — нет точного денежного ранга.

## 4. Два честных рейтинга (не смешивать)

**R-BANK / коммерческие гипотезы без ограничения 54:**
1. **A1 (кредитная ФБС вне 54)** — предварительное 1-е место, **условно**.
2. **A2 (4.1.22.2)** — предварительное 2-е место, **условно**.
3. **D1 (2.1.3 + 3.3.3)** — альтернативная стратегия захвата канала, **может вытеснить A2 по `RAC`**, данных нет.
4. **A3 (4.1.24)** — поддерживать, premium standalone проверить узким сегментом.
5. A4 FX — add-on; X1/H4 — долгий R&D. Это **не строгая численная доходная сортировка**, она требует реальных данных.

**R-54 / обязательные доработки только предоставленных 54 — группы, а не ложно точный ТОП:**
- **Уровень 0, разрешить управляемые действия:** `3.1.9` + `3.1.15` + `2.2` + `4.1.1`.
- **Уровень 1, выйти к корпоративному спросу:** `2.1.3` + `3.3.3` + `5.4.1`.
- **Уровень 2, обеспечить истинность основания:** `6.1.5` + `6.1.6` + `6.1.11` + `7.11.1`, AML `7.5.1`.
- **Уровень 3, монетизировать внутри 54:** `4.1.22.2` гарантии, `4.1.11` обеспечение; `4.1.24` защищённый расчёт как опциональный инструмент.
- **ФБС вне 54:** кредитование, полноценный риск-аппетит, FX/безналичная ликвидность, юридический клиринг.

**Уровни = порядок зависимостей**, НЕ утверждение, что мандаты гарантированно принесут больше дохода, чем гарантия.

## 5. Предметные вопросы другим трекам — требую опровержение

1. `finance-challenge`: покажите, при каких сценариях **A2** превзойдёт **D1** по `incremental_RAC`. Не голос «A2 коммерческая», а контрфакт `existing guarantee + agent quote channel`.
2. `critical-review`: согласны, что **A1 не является выбираемой ФБС из 54** и что две отдельные рейтинговые оси обязательны? Где ошибка в уровневом R-54?
3. `market`: найдите production competitor, где автономный агент **сам формирует юридически значимое обязательство и запускает новое финансирование**, а не просто исполняет уже утверждённую invoice.
4. `legal`: какие именно полномочия `3.1.9/4.1.1` позволяют агенту менять договор и брать финансирование, кроме оплаты по готовому поручению?
5. `risk`: при коррелированных решениях агентов, что делает банковский агрегированный risk owner (вне 54), чтобы избежать заморозки/неправильной выдачи?

**Правило опровержения:** `AGREE / MODIFY / REJECT` по тезисам + конкретное примечание к коду ФБС + первоисточник или исполнимый клиентский контрпример. Слова «полный консенсус» без иной независимой экспертизы запрещены.
