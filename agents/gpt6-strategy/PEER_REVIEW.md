# Cross-review и разногласия GPT-6 с текущим CONSENSUS_FBS.md

**28.10.2026. Независимая критика, не отзыв других участников.**

### Поддерживаю
- **A1** финансирование юридического лица по проверенному заказу/требованию при наличии кредитной способности вне переданных 54 ФБС.
- **A2** гарантию, но только с договорно согласованным механизмом этапного покрытия (не односторонний отзыв).
- **A3** этапное escrow с независимыми доказательствами, rollback/спорами; происхождение данных не доказывает реальность результата.
- **X1** допустим только как R&D 2036 и только после проверки законности многостороннего зачёта.

### Оспариваю / предлагаю уточнить
1. **A4 «Автономное treasury/FX» — не равнозначно A1–A3 по доказанной новой ценности.** Это зрелое направление существующих продуктов и автоматизации. Предлагаю статус `CROSS_SELL / EMBEDDED_ADD_ON` при возникновении подтверждённой A2A-сделки, а не самостоятельный «новый банковский продукт»; привязать к ФБС безналичной ликвидности/FX вне среза, 4.1.14.4 только для соответствующих финансовых инструментов. Чтобы оставить P1, нужен сильный клиентский CJM и сравнение с обычным корпоративным FX-автоматизмом.
2. **Машиночитаемый каталог финансовых предложений 2.1.3 / 3.3.3** требует статуса `DISTRIBUTION`, не только «инфраструктура»: если внешние закупочные агенты захватят инициирование сделки, это может стать критичным банковским каналом, даже без технологической новизны.
3. **A1** нельзя обещать новый доступ к кредиту просто из-за «агентности»: подтверждённый PO/инвойс и existing SCF уже используется банками. Отличительная ставка — совместная автоматизированная цепочка независимой верификации, риска, финансирования и финального исполнения без ручного перехода.
4. **BIS Project Agorá**: на странице проекта уже описано **real-value testing июля 2026** (28 участников, около CHF 800 тыс., 17 сценариев). Следовательно, статус «только прототип, real-value будет» устарел. Это не означает общедоступного банковского продукта; но особенно важно не заявлять atomic cross-border FX новым.
5. **Риск публичности**: репозиторий открыт. Не сохранять внутренние тарифы, настоящие ФБС-паспорта Сбера, реальные клиентские данные и конфиденциальные схемы. Здесь только уже присланный пользователем срез и открытый desk-research; проверить допустимость публикации всей карты отдельно.
