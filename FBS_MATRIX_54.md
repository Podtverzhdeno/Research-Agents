# FBS_MATRIX_54.md — покрытие исходной карты без подмены семантики

**54 из 54 кодов**, 6 систем. **Ревью Round 05:** предложена смена исследовательских ролей четырёх ФБС (2.1.3 и 6.1.10: B→C; 4.1.6 и 3.8: C→B). **Это не официальная переклассификация банка**; решение по инвестициям и смысловые названия ФБС не изменены. **C** означает критично для выбранного многостороннего агентного сценария, **не** обязательно для каждой отдельной банковской операции. `P` — ФБС, непосредственно обслуживающая основной банковский продукт/возможность (НЕ означает одобрение отдельной инвестиции); `C` — критический сквозной контур; `B` — полезная базовая адаптация/дополнительный продукт; `0` — нет отдельной агентной инвестиционной ставки (не означает отсутствия обычных работ). Все формулировки — **экспертные предложения**, не утверждённая нормативная архитектура.

**Вне фрагмента:** A1 требует ФБС кредитования/факторинга; A4 — FX и безналичной ликвидности; X1 — юридического многостороннего зачёта. Эти способности не следует добавлять под фиктивными номерами. Общий список ФБС банка может их содержать.
