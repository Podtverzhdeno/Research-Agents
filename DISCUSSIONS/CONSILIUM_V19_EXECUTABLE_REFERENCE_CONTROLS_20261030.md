Отдельно есть [36 bank E2E acceptance cases](CONSILIUM_V18_36_E2E_EXPECTATIONS_20261030.csv) (3 positive + 3 negative для каждой из 6 ФБС). **Ни один из этих 36 сценариев пока не выполнен на банковской системе.** Модельные тесты не ставятся как `actual=PASS` в банковском реестре.

Локально выполнен запуск 25/25 PASS; GitHub Actions [run 40972641026](https://github.com/Podtverzhdeno/Research-Agents/actions/runs/40972641026): `editorial-integrity=SUCCESS`, `consilium-time-gate=FAIL CLOSED` по отсутствию защищённого ключа/доказанных живых обсуждений. Последующее изменение workflow запускает проверки на **любом PR**, включая изменение исходного CSV, а не только определённых путей.

## Необходимая граница доверия

Эта модель **не** проверяет подлинность юридических подписей, отсутствие сговора свидетелей, полномочия банковских сотрудников, реальную AML-модель/порог, регуляторные требования, распределённую идемпотентность, settlement rails, обеспечительные договоры и стоимость риска. Все параметры/boolean и статус провайдера считаются входными данными для иллюстрации инвариантов, а **не** независимо доказанными сведениями. Для production необходима банковская реализация и подтверждённые тестовые протоколы.

### Доказательства для перехода к реальным одобрениям

1. Для **каждой** из 36 строк: commit/ref исполняемого теста в банковском стенде, timestamp, actual side effects, идентификатор тестового кейса, журнал, независимый owner/QA/Legal/Risk ACK.
2. Для **каждой** из 54 ФБС: ответ ответственного владельца на версию паспорта и отклонения V17; особый акцент 3.1.15, 4.1.1, 4.1.14.2, 4.1.13.6.2.
3. Для **каждой** из 54 ФБС: настоящие независимые агенты, 60+ минут wall clock и доказанной активности **каждого** агента, защищённые события, контроль содержательных отзывов человеком, signed attestation, защищённый ключ и обязательный status check.
4. Только после подтверждения всех внешних условий Product/Legal/Risk/InfoSec/QA владелец может изменить `BANK_APPROVAL_PENDING`. Никакая LLM подпись или этот markdown не являются банковским согласием.
