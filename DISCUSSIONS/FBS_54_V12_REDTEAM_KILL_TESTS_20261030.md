## Непримиримые альтернативы по двум новым кандидатам

**N-01 — независимое доказательство исполнения**: A — `6.1.6/6.1.7` и локальный контроль продукта; B — самостоятельная договорная услуга проверки доказательств для нескольких банковских продуктов; C — автоматическая выплата по взаимным сообщениям агентов — **REJECT**; D — `NO_NEW_FBS`, если сбор данных и escrow уже дают тот же результат. **Отсечение:** сговор двух зависимых «свидетелей» не приводит к подтверждению и выплате.

**N-02 — связанные собственные банковские обязательства**: A — действующие `4.1.2 + 4.1.10.* + 4.1.22.2 + 4.1.24 + 5.6.2` с BPM; B — отдельно оформленная банковская обязанность сопровождать допустимые изменения пакета собственных финансовых обязательств; C — «автоматически изменить все внешние договоры и откатить финальный платёж» — **REJECT**; D — `NO_NEW_FBS`, если BPM уже обеспечивает сопоставимый юридический и экономический итог. **Отсечение:** частичная ошибка одного продукта не скрывается за статусом всей сделки `SUCCESS`.
